# 验收说明

## 两种证据不混用

1. **本地界面基准**：此前 Cursor 3.24.18 的实际页面、下拉、动态提示、图标及原生菜单巡检，确定应发布的目标资源。
2. **公开安装器验证**：在完全隔离的原厂副本、测试用户目录与扩展目录中执行安装、重复安装和独立恢复；不启动该测试副本 GUI，不对真实账号发请求。

安装器重建出的受补丁控制资源及运行时必须与前述基准的 SHA-256 一致；这不等于在其它电脑、其它平台或未触发远端场景完成了实机验收。

## 本地界面基准的已验证范围

- 11 类智能体设置与下拉、14 项场景回归、48 次设置/菜单切换。
- 实际聚焦窗口分别核验：智能体原生菜单 41 项，编辑器 230 项。
- 7,360 个有效词典键的冲突和占位符机械检查；3,642 条短文案运行时夹具。
- 21 处语言包占位符兼容问题已修正；2,435 处不应翻译的原始菜单元数据恢复。
- 新增隐藏界面源码补漏 200 处；189,267 个比较操作及 184,428 个受保护字面量不变量通过。

译文审核采用全量机械检查与重点语境复核；**没有把每个词条都逐条人工认证**。历史滚动检查曾见 1,510 个编辑器设置，最近一轮实测 1,506 项；4 个历史设置没有在当时搜索视图注册，未冒充本轮实测。

## 公开安装器验证

可在仓库查看 `integration-report.json` 的结构化结果；该报告只有通过隔离安装及独立恢复后才生成。

```bash
python3 -m unittest discover -s tests -v
python3 scripts/check_release.py
python3 scripts/integration_check.py --original-app "/path/to/Original Cursor.app" --report docs/integration-report.json
```

集成测试会创建并在成功后清理自己的临时测试目录，不修改或启动输入应用。失败时保留它自己创建的临时副本以便检查，原输入仍保持不变。

`install.py check-update` 和 `install.py preview` 是本地只读检查，不联系 Cursor 更新服务器，也不对未知构建尝试迁移。它们会核对应用版本、构建提交和目标文件 SHA-256；预览仅在文件与当前受支持原版完全匹配时生成字节差异片段。新版本必须先由维护者审核并更新 profile 与补丁，因此本检查不代表自动适配未来版本。

## 不能从这些测试推出的结论

- 不能推出 Windows、Linux、Intel Mac 或其它 Cursor 构建可用。
- 不能推出任意未来/第三方文字都已汉化。
- 没有执行购买、真实智能体任务、SSH 登录、删除或系统权限批准。
- 没有声称本地临时签名与官方自动更新、所有第三方插件完全兼容。
