- 项目标题：Cursor-CN｜Cursor 汉化中文补丁；GitHub 仓库地址使用 Cursor-CN。
- 首版只声明支持已验证的 macOS Apple Silicon、Cursor 3.24.18 对应构建；其它版本、Intel 和 Windows 不强行套补丁。
- 不上传 Cursor.app、完整 Cursor 源码、原厂备份、账号、聊天、截图中的私人内容或本机路径。
- 发布可验证的差异数据、原创安装与恢复代码。未明确标注许可证的上游完整工具和词典不复制进仓库；依赖按固定提交及 SHA-256 在用户安装时获取。
- 安装采用新副本准备、精确版本/哈希验证、完整原版保留、事务切换；重复安装不重复签名。
- 本机已部署 Cursor 不再修改或重签名；发布验证只在隔离副本进行。
- 验收：单元测试、全资源重建比对、隔离签名检查、恢复测试、发布内容隐私扫描、GitHub 远端和 Release 下载校验。
