# Cursor-CN｜Cursor 汉化中文补丁 v1.0.0

## 下载与使用

下载 `Cursor-CN-v1.0.0-macOS-arm64.zip`，解压后双击 **一键安装.command**。

**首版仅支持 macOS Apple Silicon（M 系列）及 Cursor 3.24.18 的指定构建。** 不匹配会停止，不会强行覆盖。需要 Python 3.9 或以上版本；首次下载依赖需要联网，不需要 API Key。

## 本次整理

- 中文显示补漏与语境修正，包含设置、隐藏选项、动态提示、图标和原生菜单。
- 精确版本和 SHA-256 校验，下载依赖同样锁定哈希。
- 完整保留原厂应用；提供一键恢复与不依赖仓库继续存在的独立恢复入口。
- 重复安装不重新签名；不清理账号、聊天或项目数据库。
- 补丁差异分发，不包含 Cursor 程序、原厂备份、完整上游工具或微软 VSIX。

## 重要边界

首次启动可能出现 macOS 系统授权提示，必须由用户自行判断；没有自动批准或自动续期功能。采用应用范围本地签名，官方更新签名检查可能不兼容，**升级前先恢复官方原版**。

本地界面基准和隔离安装/恢复测试分开记录；不将未触发远端场景、其它平台或其它 Cursor 版本写成全部验收通过。详见仓库 README、第三方许可说明和验收记录。

附件 `SHA256SUMS` 可核对下载 ZIP 的 SHA-256。
