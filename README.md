# Cursor-CN｜Cursor 汉化中文补丁

把这次逐页修正的 Cursor 中文界面整理成**可校验、可回退的一键部署补丁**。

**首版适用：macOS Apple Silicon（M 系列）+ Cursor 3.24.18 指定构建。** 不是官方产品，不是 Cursor 安装包，也不承诺兼容任意版本。版本或文件哈希不一致时会停止，不会硬打补丁。

本仓库提供补丁、安装与恢复工具的公开源码。首版仅适配下方列出的指定 Cursor 构建。

## 一键安装

1. 在 [Releases](https://github.com/Mars535821089-ops/Cursor-CN/releases/latest) 下载 `Cursor-CN-v1.0.0-macOS-arm64.zip`，解压。
2. 保存 Cursor 中的工作，双击 **`一键安装.command`**。

也可以下载仓库后，在该目录运行：

```bash
bash install.sh
```

需要 Python 3.9 或以上版本，以及 macOS 自带的 `codesign`。不需要 Node.js、GitHub 登录或 API Key。没有 Python 时安装器会提示安装，不会擅自安装 Xcode 或索要管理员密码。

**一键部署不等于免除系统安全确认。** 首次启动修改后的应用，macOS 可能重新询问钥匙串、文件或设备权限；这些必须由你自己判断并确认。补丁不会代点弹窗、修改授权时限、自动续期、关闭 SIP/Gatekeeper 或放宽全局系统策略。

### 安装前先检查

双击 `检查环境.command`，或执行：

```bash
python3 scripts/install.py status
```

Cursor 不在默认位置时：

```bash
python3 scripts/install.py install --app "$HOME/Applications/Cursor.app" --quit-cursor
```

## 本补丁包含什么

- 智能体、编辑器、设置、菜单和下拉选项的中文显示补漏。
- “套餐与用量”“代码缩略图”“个人资料”等语境修正。
- 代码审阅工具栏位置使用“顶部导航栏 / 悬浮工具栏”，不再直译成“面包屑 / 浮动岛”。
- 动态拼接和轮播提示的整句处理，保留界面框架的节点及图标。
- 原生 macOS 菜单、官方简体中文语言包兼容修正。
- 精确版本和 SHA-256 校验、重复安装检测、完整原版保留及独立恢复入口。

真实品牌、模型名、命令、代码、路径、配置值和用户内容有意保留原文。第三方网页、未来版本和未触发的远端状态不属于“已全部验证”的承诺范围。

## 安装流程与安全边界

1. 检查平台、构建号和原版资源哈希。不支持的版本直接停止。
2. 按固定提交及 SHA-256 下载依赖，在隔离目录重建已审核的翻译脚本。
3. 准备 Cursor 的新副本，应用差异补丁并校验全部目标文件。
4. 仅为新副本及其 Electron 助手执行应用范围的本地临时签名。
5. 使用 Cursor 官方扩展管理器注册匹配版本的微软语言包；不改写扩展 JavaScript，不关闭扩展校验。
6. 保留完整原厂应用后切换副本，再写入语言配置。失败会尽量回到原版，并保留诊断/恢复材料。

不读取或清理账号、聊天、Cookie、密钥或项目数据库，不修改 `settings.json`。首次安装需要联网下载约数兆依赖；界面翻译使用离线词典，不将界面文本提交给在线翻译服务。Cursor 自身的正常联网行为不受此补丁控制。

**重复运行已安装版本不会重新签名**，避免无意义的重复授权。应用目录不可写、退出时有未保存内容或依赖校验失败时，会明确停止；不会自动 `sudo` 或强制杀进程。

## 恢复官方原版

双击 **`一键恢复.command`**，或使用安装完成时打印的独立恢复入口：

```text
~/Library/Application Support/CursorChinesePatch/Backups/<安装编号>/恢复官方原版.command
```

独立恢复入口不依赖本仓库目录继续存在。完整原厂应用保存在原应用同目录下的 `.Cursor-Chinese-Patch-Original-<安装编号>.app`，恢复时会保留当前补丁应用，不删除账号、聊天或项目。

安装后自行改动过的语言配置会保留并提示，不盲目覆盖。恢复默认不卸载微软语言包扩展，也不删除额外安装的扩展。

### 升级 Cursor 前必读

本地签名可能使 Cursor 原生更新器的签名检查失败，官方更新也可能覆盖补丁。**升级前先恢复官方原版，正常升级后等待新版本适配。** 不要把此补丁强行用于其它版本，也不要从不可信渠道下载旧版 Cursor。

## 验证与维护

本仓库中的 `scripts/` 包含安装、补丁生成/应用、离线语言资源构建、完整性检查、恢复和归档的源码；`patches/` 包含此版本的差异数据与中文覆盖词条；`tests/`、`docs/` 和 `.github/workflows/` 分别提供自动测试、验收记录与持续集成。发布流程使用已提交文件生成 ZIP；仓库新增修正只有重新发布后才会包含在 Release 中。

### 源码级漏译复查

只读扫描了指定构建全部 46 个 `out/` JavaScript 文件（不重复扫描已有注入词典），盘点 116 个内置扩展清单，并解析 Cursor 自有扩展的 23 个 JSON 资源。累计新增 **799 处源码字面量修正、972 处 NLS 消息修正**，涵盖模式说明、设置描述、占位提示、无障碍标签、原生菜单、内置扩展命令，以及上传数据、工作区信任和签名校验等安全提示。2026-10-30 复查增加 56 处 NLS 修正，包括调试无障碍帮助、扩展信任策略、远程连接提示、搜索选项与窗口设置。

审核词条集中在 `patches/reviewed-ui.json`：`translations` 仅用于 AST 确认的界面位置；`nls_translations` 仅用于语言资源，不扩大源码替换范围。`ui-review-3.24.18.json.gz` 是接在原有补丁之后的精确字节差异；27 个资源逐个锁定修改前后的大小和 SHA-256。命令 ID、配置键、代码逻辑与用户内容不作全局替换。安装、预览、检查和独立恢复均使用同一条补丁链，未知文件会停止。

**这不是“零漏译”认证。** 审计仍列出 644 个动态模板候选；修正后的 NLS 仍有 511 个含英文而不含汉字的候选，其中包括品牌、快捷键、开发诊断及尚待审核的文案。模板插值、混合语言 HTML、远端内容及第三方扩展运行时不能仅凭静态计数确认。详细方法和本轮未执行的实机验证见[验收说明](docs/verification.md#源码级漏译复查的新增证据)。

本轮仅更新仓库，没有改写本机 Cursor 应用或用户数据。旧补丁应用不满足新增最终指纹，不能原地叠加安装；需用其原有恢复入口还原，再使用更新后的源码安装。

### Cursor 更新后的检查与预览

目前确认可用的是 VS Code 兼容的简体中文语言包；Cursor 专属界面仍需对指定应用资源打精确差异补丁。没有找到可替代该补丁、且由 Cursor 官方承诺更新兼容的完整本地化扩展接口，因此不能承诺 Cursor 更新后免维护。补丁会更改隔离副本中的应用资源并重新本地签名；它不会保留原厂签名，也不应直接用于原版应用或期待原生更新器无缝更新。

每次 Cursor 更新前先恢复原版。更新完成后，可先对新版本执行只读检查和预览：

```bash
python3 scripts/install.py check-update --app "/Applications/Cursor.app"
python3 scripts/install.py preview --app "/Applications/Cursor.app"
```

两条命令输出机器可读 JSON，包含版本、构建提交、每个目标文件及运行时资源的 SHA-256。`preview` 对已知原版只展示精确补丁的字节范围和有限长度的变更片段，不写入文件；已安装补丁则报告没有待应用差异。遇到新版本、未知源码、缺失文件或部分修改时会明确标记不支持，退出码为 2，不提供猜测性补丁，也不替换任何文件。此检查读取本机应用，不查询 Cursor 更新服务器；新版本仍需维护者审核并发布新指纹和差异数据。

如需同时核对官方公开最新系列，显式执行联网只读命令：

```bash
python3 scripts/check_versions.py --app "/Applications/Cursor.app"
```

此命令从 [Cursor 官方下载页](https://cursor.com/download) 读取唯一的 `Latest` 系列标记，并要求存在同系列官方 macOS ARM64 链接。输出分别比较本机版本、仓库支持版本和官方系列；不上传设备标识、不下载应用或自动信任新指纹。它只核实公开系列，不据此猜测完整补丁版本、构建号或语言资源兼容性。同系列返回 `same_series_patch_level_unknown`，不能解释成“已是最新小版本”。退出码 2 表示本机/仓库系列落后或本机补丁状态不支持，1 表示网络或页面校验失败；失败不会伪装成“无更新”。

**2026-10-30 核验：本机与可安装 profile 仍为 3.24.18；已下载官方最新系列的 3.27.22 样本，完成独立资源适配预览，但未开放安装。** 新样本通过深度签名和装订公证票据校验，在只读挂载中完成 1,119 处源码字面量差异验证，并从官方语言包重建 NLS，再叠加 1,624 处审核/精确原文迁移。未将旧版运行时直接注入新版，也未猜测偏移。来源、命令及明确剩余清单见 [3.27.22 资源适配说明](docs/resource-adaptation.md)。

`check_versions.py` 会分别报告“可安装支持”和“资源预览”，不会把预览等同于已经部署。本机仍是旧补丁状态，新增审核修正尚未生效；原有资源不满足新增最终指纹。本次未升级应用、覆盖资源、重新签名或修改用户配置。禁止重新签名时不能应用本仓库的专属 UI 资源补丁；完整安装与 GUI 验收仍未完成。

这里的“源码”指本补丁项目可公开分发的全部实现与数据，不包括 Cursor 或第三方语言包的原始程序、完整上游工具以及本机私人巡检材料。

```bash
python3 -m unittest discover -s tests -v
python3 scripts/check_release.py
```

维护者可使用 `prepare` 在原版的隔离副本上重建、校验和签名，不替换正在使用的应用、不写用户配置：

```bash
python3 scripts/install.py prepare --app "/path/to/Original Cursor.app" --output "/path/to/Prepared Cursor.app"
```

安装/恢复验证与界面审查的范围见 [验收记录](docs/verification.md)。原始大体积应用和私人巡检记录不随仓库发布。
